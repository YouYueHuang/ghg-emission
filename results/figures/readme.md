# 專案資料夾結構與說明 (Project Directory Overview)

本專案包含以下資料夾結構，點擊名稱即可切換至對應的目錄：

---

## 📁 目錄選單

* 📂 [Digital_Elevation_Model](./Digital_Elevation_Model) — 數位高程模型 (DEM)
* 📂 [Merged](./Merged) — 整合/合併資料庫
  * 📂 [Business](./Merged/Business) — 商業區資料
  * 📂 [Hum](./Merged/Hum) — 濕度資料 (Humidity)
  * 📂 [Industry](./Merged/Industry) — 工業區資料
  * 📂 [NDVI](./Merged/NDVI) — 植生指標 (Normalized Difference Vegetation Index)
  * 📂 [no2](./Merged/no2) — 二氧化氮整合資料
  * 📂 [ozone](./Merged/ozone) — 臭氧整合資料
  * 📂 [PBLH](./Merged/PBLH) — 邊界層高度 (Planetary Boundary Layer Height)
  * 📂 [Residential](./Merged/Residential) — 住宅區資料
  * 📂 [Road total length](./Merged/Road%20total%20length) — 道路總長度
  * 📂 [SWD](./Merged/SWD) — 短波輻射 (Shortwave Radiation Downward)
  * 📂 [Temp](./Merged/Temp) — 溫度資料
  * 📂 [troposphere_ozone](./Merged/troposphere_ozone) — 對流層臭氧
  * 📂 [U](./Merged/U) — 東向風速 (U-component of wind)
  * 📂 [V](./Merged/V) — 北向風速 (V-component of wind)
  * 📂 [VIIRS](./Merged/VIIRS) — VIIRS 夜間燈光/衛星遙測資料
