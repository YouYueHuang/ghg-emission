# NO₂ 濃度預測模型實驗報告：春季組別 vs 全年度組別

本專案旨在利用 XGBoost 機器學習模型預測大氣中氮氧化物（$\text{NO}_2$）的濃度。本文檔記錄並比較兩種不同訓練資料切分策略（僅春季資料 vs 全年度資料）對模型預測成效的影響。

---

## 📌 專案簡介

- **預測目標**：大氣地表 $\text{NO}_2$ 濃度 (`NO2_gnd`)
- **使用模型**：XGBoost Regressor
- **特徵數量**：18 個（包含氣象、衛星遙測、地表土地利用等特徵，如 `troposphere_ozone`, `VIIRS`, `NDVI`, `PBLH`, `Temp`, `Hum` 等）
- **實驗目的**：評估增加季節多樣性與訓練資料量對於模型泛化能力與預測精準度的提升效果。

---

## 📊 1. 資料量與過濾統計 (Data Filtering & Sample Sizes)

資料處理過程中針對缺值進行篩選過濾，兩組實驗均使用相同的測試集指紋進行客觀比較。

| 評估項目 | 春季模型 (`spring`) | 全年度模型 (`full_year`) | 說明與差異 |
| :--- | :--- | :--- | :--- |
| **原始總列數** | 54,600 | 217,160 | 全年涵蓋 2023 全年 12 個月 |
| **過濾後保留列數** | 41,214 | 142,321 | — |
| **資料移除率 (%)** | **24.5%** (移除 13,386 列) | **34.5%** (移除 74,839 列) | 全年缺值比例較高 |
| **主要缺失特徵** | `troposphere_ozone` (10,217 列) | `troposphere_ozone` (62,994 列) | 兩者均以對流層臭氧缺失為主要過濾原因 |
| **訓練集筆數** | 32,971 | 134,078 | 全年訓練集規模約為春季模型的 4 倍 |
| **測試集筆數** | **8,243** | **8,243** | **完全相同** (測試集指紋: `3e9e2230c6c9`) |

## 📈 2. 測試集模型預測成效比較 (Evaluation Metrics)

下表為模型在獨立測試集（$N = 8,243$）上的各項評估指標比較：

| 評估指標 (Metric) | 春季模型 (`spring`) | 全年度模型 (`full_year`) | 成效提升 / 變化 |
| :--- | :--- | :--- | :--- |
| **相關係數 ($r$)** | 0.7314 | **0.7765** | **+0.0451** (線性相關性提升) |
| **決定係數 ($R^2$)** | 0.5204 | **0.5997** | **+0.0793** (總變異解釋力提升近 8%) |
| **均方根誤差 ($\text{RMSE}$)** | 4.9515 | **4.5239** | **-0.4276** (預測絕對誤差降低) |
| **平均偏差 ($\text{MD}$)** | +0.7509 | **-0.0691** | **接近 0** (顯著修正春季模型的系統性高估) |
| **平均絕對百分比誤差 ($\text{MAPE}$)** | 75.24% | **53.69%** | **-21.55%** (相對誤差大幅改善) |

## ⚙️ 3. 模型訓練過程與動態 (Training Dynamics)

| 訓練項目 | 春季模型 (`spring`) | 全年度模型 (`full_year`) |
| :--- | :--- | :--- |
| **Validation RMSE (初始 0 輪)** | 7.2183 | 7.0604 |
| **最佳 Early Stopping 輪數** | 182 輪 | 686 輪 |

## 💡 實驗結論與發現

1. **基準一致性**：兩次實驗採用**完全一致的測試集**（指紋 `3e9e2230c6c9`），確保評估指標具備嚴謹的客觀可比性。
2. **整體成效提升**：引進全年度訓練資料後，$R^2$ 由 `0.5204` 大幅提升至 `0.5997`，且 $\text{MAPE}$ 相對誤差降低了近 `21.55%`。
3. **偏差顯著收斂**：春季模型存在約 `+0.75` 的偏高估傾向，全年度模型將平均偏差（$\text{MD}$）校正至 `-0.0691`，大幅降低模型的系統性偏差。
4. **學習能力擴展**：全年度模型的 Early Stopping 輪數延伸至 686 輪，顯示在資料量放大且涵蓋四季氣候變化後，模型能學到更複雜且穩健的特徵組合。
